# 💄 متجر الجمال - متجر إلكتروني لتجارة مواد التجميل العصرية

موقع إلكتروني تجريبي وتفاعلي مخصص لعرض وبيع مواد التجميل ومستحضرات العناية بالبشرة، يتميز بتصميم أنيق وعصري ومتجاوب بالكامل مع كافة الشاشات (الهواتف الذكية، الأجهزة اللوحية، والحواسيب).

---

## 🚀 الميزات الرئيسية للموقع
- **تصميم عصري وجذاب:** واجهة مستخدم مصممة خصيصاً لمتاجر التجميل والعناية الشخصية باستخدام ألوان مريحة وعصرية.
- **تخطيط متجاوب (Responsive):** يعمل بكفاءة عالية على جميع أحجام الشاشات بفضل تقنية الـ Flexbox و CSS Grid.
- **عرض المنتجات:** قسم خاص لعرض المنتجات مع الصور، الأسماء، الأسعار، وأزرار "أضف للسلة".
- **شريط علوي تفاعلي:** يتضمن شعار المتجر وروابط التنقل السريع (الرئيسية، المنتجات، من نحن، اتصل بنا).
- **خطوط عربية أنيقة:** مدعوم بخخط Cairo عبر Google Fonts لضمان وضوح وقراءة مريحة للنصوص باللغة العربية.

---

## 🛠️ التقنيات المستخدمة
- **HTML5:** لهيكلة صفحات الموقع.
- **CSS3:** لتصميم وتنسيق الواجهات وإضافة التأثيرات البصرية والحركية.
- **Google Fonts:** لاستخدام الخط العربي (Cairo).
- **Unsplash API:** لجلب صور عالية الجودة خاصة بمواد التجميل.
